# Acvtividad 02 - Maching Learning
En este repositorio se encuentra el archivo de [la actividad](actividad_02.md).

Se usa una libreria personal para el proceso de compilado [bld.h](src/bld.h).
solo compila
``` sh
gcc -o bld bld.c
```
y ejecuta
``` sh
./bld
```

Se usan las librerias de manejo de imagenes del proyecto [stb libraries](https://github.com/nothings/stb).
